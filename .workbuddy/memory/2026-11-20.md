### 本次新增的两个教学点（此前未讲透）
1. **204 与统一响应体的真实冲突**：HTTP 规范下 204 不得带 body，而 `code/msg/data` 本身就是 body。给出 A(严格 204) / B(200+data:null) 两种工程取舍，并建议本项目走 B（前端拦截器只认 code 一个分支）。
2. **登录失败不回 404 的原因**：用户枚举攻击——"用户不存在 404 / 密码错 401"会让攻击者靠状态码差异探测账号是否存在；统一 401。顺带纠正密码错 = 401 而非 400。
3. 补充：`/api/auth/login` 中 login 实为动词，严格 REST 写法是 `POST /api/tokens` 或 `/api/auth/sessions`。
