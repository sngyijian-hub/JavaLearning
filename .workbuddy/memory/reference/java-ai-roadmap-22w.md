四条执行规则（比计划本身更重要）
1. 一周只推一个阶段，不跨阶段跳。唯一允许的并行是「并行轨」。
2. 每周日花 1 小时验收：过了就翻页；没过就记进踩坑日志、下周补，绝对不重排整个计划。
3. ★★★★★ 落后时，砍 ★★★ 的去补 ★★★★★，不要反过来。优先级错了比进度慢更致命。
4. 唯一允许并行的两条线：主线（工程）+ 副线（408 / 刷题）。超过两条线，五个方向都会半懂。
vibecoding 分阶段开关
W1–W8 基本禁止（0%）：只允许让 AI 解释报错原文、解释概念、解释你看不懂的代码；代码全部自己写。
W9 起放开 30–50%：可让 AI 生成 DTO/VO、Mapper XML、单测骨架、前端页面、Dockerfile、正则。
必须自己写：表设计、接口设计、核心业务、权限、缓存策略、RAG 检索链路。
铁律：AI 生成的每一行代码，你都要能讲清它为什么这么写。讲不清就删掉重写。
