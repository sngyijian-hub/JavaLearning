# RESTful 接口填空练习（W1 · 自己写）

> 用法：把 `___` 换成你自己的内容。每条接口只写四行 + 一个 JSON 块。  
> 对照示例：`docs/api-design.md` 里的第 1、2 条（GET 列表 / POST 新增）。

## 一、死记这四行公式

写任何一条接口，都按这个顺序填：

```
方法 + 路径：  __GET_   /api/资源复数[/ {id}]
入参：        放在哪里（path / query / body）+ 字段名 + 类型 + 是否必填
出参：        code / msg / data 三段，data 里放真正返回的数据
状态码：      成功用 2xx，客户端错用 4xx，服务端错用 5xx
```

## 二、状态码速查（抄这张表）

| 场景               | 状态码 |
| ---------------- | --- |
| 查列表 / 查详情 / 修改成功 | 200 |
| 新增成功（创建了新资源）     | 201 |
| 删除成功（没有内容可返回）    | 204 |
| 参数格式错 / 校验不通过    | 400 |
| 没登录 / token 无效   | 401 |
| 登录了但没权限          | 403 |
| 资源不存在            | 404 |
| 服务端异常            | 500 |

## 三、示范一条（换个资源：图书）

- 方法：`GET`
- 路径：`/api/books/1`
- 入参（path）：`id` int 必填，写在 URL 的 `{id}` 位置
- 出参（data）：`id` int；`title` string；`author` string
- 状态码：成功 `200`；找不到 `404`

```json
{
  "code": 200,
  "msg": "success",
  "data": { "id": 1, "title": "Java 基础", "author": "张三" }
}
```
